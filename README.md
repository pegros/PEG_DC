# ![Logo](/media/Logo.png) &nbsp; SFPEG **DC** Components


## Introduction

This package contains a set of Apex classes and LWC components extending the capabilities of the
**[PEG_LIST](https://github.com/pegros/PEG_LIST)** package in a **Data Cloud** and / or **AI**
context. 

For the time being, it mainly provides query access to Data Cloud data via native SQL queries and
to data generated by AI Prompts, for display in the **[sfpegListCmp](https://github.com/pegros/PEG_LIST/blob/master/help/sfpegListCmp.md)** component.

They are based on :
* the Apex / Metadata framework implemented in the **[PEG_LIST](https://github.com/pegros/PEG_LIST)** package
* standard features provided by the **[ConnectApi](https://developer.salesforce.com/docs/atlas.en-us.apexref.meta/apexref/apex_classes_connect_api.htm)** Apex namespace
* standard features provided by the **[sfsqlquery](https://developer.salesforce.com/docs/data/data-cloud-query-guide/guide/dc-apex-query.html)** Apex namespace.

These components were built as contributions or examples for former and ongoing Advisory assignments by 
[Pierre-Emmanuel Gros](https://github.com/pegros). 


## Repository Content

This repository contains a whole set of Apex extension classes for use in `sfpegList`
metadata records (see  **[sfpegList-core](/help/sfpegListPkgCore.md)** package) 
to query data in **Data Cloud** or generated by **AI Prompts**:
* **[sfpegDataCloudQueries_SVC](/help/sfpegDataCloudQueries.md)** enabling to execute
standard ANSI SQL queries on **Data Cloud** (from both _Home Org_ and _Companion_ Orgs)
* **[sfpegDataCloudQueriesV3_SVC](/help/sfpegDataCloudQueriesV3.md)** providing the same
features as **sfpegDataCloudQueries_SVC** but relying on the new **sfsqlquery** Apex framework
(synchronous queries only)
* **[sfpegPromptQueries_SVC](/help/sfpegPromptQueries.md)** enabling to invoke an
**AI Prompt** to retrieve a results
standard ANSI SQL queries on **Data Cloud** 
* **[sfpegPrompts_SVC](/help/sfpegPrompts.md)** enabling to query the list of
available Prompts on an Org

These `sfpegList` metadata records may then be used within **[sfpegListCmp](https://github.com/pegros/PEG_LIST/blob/master/help/sfpegListCmp.md)** components or any of its wrapping components of the
**[sfpegList-utilities](/help/sfpegListPkgUtilities.md)** package.


## Installation

⚠️ As a prerequisite, the latest version of the **[sfpegList-core](/help/sfpegListPkgCore.md)** 
package should be installed on your Org.

ℹ️ As the **ConnectApi** Apex class induces multiple implicit dependencies requiring **Data Cloud**
specific features on scratch Orgs, it is currently impossible to distribute the content of this
repository as an **unlocked package** (as for **[PEG_LIST](https://github.com/pegros/PEG_LIST)**).
Therefore **DataCloud** and **AgentForce** should be active on your Org when you deploy these
components.

The following two options are therefore available for package installation:
* **Git** and **SF CLI** Deployment
* **Quick Direct Deploy** button

⚠️ Pay attention to also grant users with the proper **Data Cloud** and / or **Agent AI** specific
permissions to be able to access **Data Cloud** data and / or invoke **AI Prompts**.



### **Git** and **SF CLI** Deployment

To retrieve the SFDX project, you may simply execute a git clone from the GitHub repository.
```
git clone git@github.com:pegros/PEG_DC.git
```

Via SFDX you may then deploy it on you Org
```
sfdx force:source:deploy -u <yourOrgAlias> -w 10 --verbose -p force-app
```

### Quick Direct Deploy

For a quick and easy deployment, you may alternatively use the following deploy button
leveraging the **[GitHub Salesforce Deploy Tool](https://github.com/afawcett/githubsfdeploy)**
implemented by [Andrew Fawcett](https://andyinthecloud.com/2013/09/24/deploy-direct-from-github-to-salesforce/).

## Release Notes

ℹ️ As this repository is not distributed as **unlocked package**, there is no real
package version. This section however summarizes the timeline and contents of the main
evolutions made.

### Jan 2026

First version of the package.
* Transfer of the **[sfpegDataCloudQueries_SVC](/help/sfpegDataCloudQueries.md)** Apex class
from the **[PEG_LIST](https://github.com/pegros/PEG_LIST)** package to the **PEG_DC** package
for easier deployment
* Addition of the **[sfpegPromptQueries_SVC](/help/sfpegPromptQueries.md)** and 
**[sfpegPrompts_SVC](/help/sfpegPrompts.md)** Apex classes

### Feb 2026

Changes done:
* Added new `ESC_SINGLE(((...)))` rework function in the 
**[sfpegDataCloudQueries_SVC](/help/sfpegDataCloudQueries.md)** Apex class
to handle cases where single quotes need to be escaped properly in Data Cloud SQL queries (e.g. for Semantic Search).

### Oct 2026

Changes done:
* Addition of the **[sfpegDataCloudQueriesV3_SVC](/help/sfpegDataCloudQueriesV3.md)** Apex class,
new variant of the **[sfpegDataCloudQueries_SVC](/help/sfpegDataCloudQueries.md)** Apex class
relying on the new **sfsqlquery** Apex framework instead of **ConnectApi.CdpQuery**
(synchronous queries only).
